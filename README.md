# Portofolio Pribadi — Yesica Arthadita Sibarani

Website portofolio pribadi yang dibangun menggunakan **Astro** dan dipublikasikan melalui **GitHub Pages**.

- **Tautan Website Publik:** https://github.io
- **Repositori GitHub:** https://github.com
- **Tema Dasar:** Seasons oleh `nicomiguelino` (telah dikustomisasi penuh)

## Daftar Fitur yang Diimplementasikan

### Fitur Standar & Bawaan
1. **Mode Gelap/Terang & Tema Musiman:** Tombol pengubah tema tampilan (Light/Dark Mode dan palet warna musim).
2. **Blog Berbasis Markdown:** Memuat 2 artikel terkait statistika dan pemrograman Python menggunakan Astro Content Collections.
3. **Halaman Proyek Terpisah:** Menampilkan 3 proyek latihan kuliah (Microsoft Excel, Python, dan Esai Akademik) dengan tautan aktif menuju dokumen proyek.
4. **Linimasa Pengalaman (Experience):** Riwayat perjalanan pendidikan di Program Studi S1 Statistika Universitas Cenderawasih.
5. **Formulir Kontak Interaktif:** Halaman kontak terpisah (`/contact/`) untuk mengirim pesan dan masukan langsung via email.
6. **Dua Bahasa (Indonesia & Inggris):** Widget alih bahasa interaktif untuk menerjemahkan halaman secara otomatis.
7. **Pencarian Konten:** Fitur pencarian cepat untuk menelusuri artikel dan halaman.
8. **SEO Dasar & Umpan RSS:** Dilengkapi metadata halaman, Open Graph, sitemap, serta dukungan RSS feed.
9. **Animasi Transisi Halus:** Transisi antarhalaman yang responsif di layar ponsel maupun desktop.

### Fitur Kustom Tambahan (Diajukan untuk Penilaian)
10. **Kalkulator Statistika Deskriptif (`/statistik/`):** Alat hitung interaktif untuk mencari Jumlah Data ($n$), Mean, Median, Modus, Varians Sampel ($s^2$), dan Standar Deviasi ($s$).
11. **Mini-Game Tebak Angka (`/game/`):** Permainan interaktif berbasis logika algoritma pencarian biner (*binary search*) dan probabilitas.
12. **Widget Fakta Acak Statistika & Waktu Lokal WIT:** Kartu interaktif di halaman beranda yang menampilkan fakta acak statistika/Python serta jam *real-time* zona waktu Jayapura (WIT).
